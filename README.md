# 🌙 MOON Music

MOON Music is a modern AI-powered music streaming web application that delivers personalized song recommendations based on user emotions and listening preferences. Built with a futuristic glassmorphism interface and immersive moon-inspired aesthetics, the platform combines mood detection, smart music discovery, playlist management, and responsive design into a seamless user experience.

---

## 🚀 Features

### 🎭 Emotion-Based Music Recommendation
- Detects user emotions using camera-based mood detection
- Dynamically recommends songs based on emotional state
- Supports mood categories such as happy, sad, energetic, romantic, and calm

### 🎵 Smart Music Experience
- Integrated audio player with playback controls
- 30-second song previews using Deezer API
- Recently played tracks and listening history
- Favorites and personalized recommendations

### 👤 Authentication System
- User login and signup interface
- Local storage-based session management
- User profile dashboard

### 📂 Playlist Management
- Create and manage playlists
- Playlist categorization by mood and genre
- Personalized music collections

### ⚙️ Settings & Customization
- Theme switching support
- Adjustable preview duration
- Auto-play functionality
- Notification preferences

### 🎨 Modern UI/UX
- Glassmorphism design system
- Fully responsive interface
- Animated transitions and hover effects
- Cosmic moon-inspired visual theme
